Git MergeTool & DiffTool Config

Use Meld, a free visual diff and merge tool, to resolve merge conflicts and compare branches side by side instead of reading raw <<<<<<< markers.

Setup Resolve conflicts Compare branches

1 · Configure Meld from the command line

Run these once. --global writes to your user-level ~/.gitconfig, so they apply to every repository.

# merge tool
git config --global merge.tool meld
git config --global mergetool.meld.path "D:/installed_tools/meld/Meld.exe"
git config --global mergetool.keepBackup false      # don't leave *.orig files behind

# diff tool
git config --global diff.tool meld                  # used by: git difftool
git config --global diff.guitool meld               # used by: git difftool --gui
git config --global difftool.meld.path "D:/installed_tools/meld/Meld.exe"
git config --global difftool.prompt false           # open Meld without asking per file
Path: replace the Meld.exe path with your install location. Use forward slashes on Windows. On macOS or Linux, if meld is on your PATH, you can skip the *.path lines.

2 · The resulting .gitconfig

You can also paste this straight into ~/.gitconfig (on Windows: C:\Users\<you>\.gitconfig).

[user]
    name  = Your Name
    email = you@example.com

[diff]
    tool    = meld
    guitool = meld
[difftool "meld"]
    path = D:/installed_tools/meld/Meld.exe
[difftool]
    prompt = false

[merge]
    tool = meld
[mergetool "meld"]
    path = D:/installed_tools/meld/Meld.exe
[mergetool]
    keepBackup = false
🧠Check which settings are actually in effect, and which file each comes from, with git config --global --list --show-origin.

3 · Resolve a merge conflict

When git merge or git pull reports conflicts, open each conflicted file in Meld.

git mergetool                             # opens Meld for each conflicted file
                                          # (left: yours · middle: result · right: theirs)
                                          # pick changes, save, close Meld

git status                                # all files should now be staged
git commit -m "Resolve merge conflict"
Changed your mind? Run git merge --abort to return to the state before the merge started.

4 · Compare branches

git diff prints the changes in the terminal. git difftool shows the same changes in Meld.

In the terminal

git diff main..feature/my-work
git diff main..feature/my-work -- articles/most-used-git-cmds.html

In Meld

git difftool main..feature/my-work                    # one file at a time
git difftool main..feature/my-work -- articles/most-used-git-cmds.html
git difftool -d main..feature/my-work                 # whole folder tree in one window
🧠-d (directory diff) opens every changed file in one Meld window instead of launching Meld once per file. Much faster for reviewing a whole branch.
