Java Singleton

A Singleton guarantees a class has exactly one instance and gives a single global access point to it — think configuration managers, connection pools, loggers.

Private constructor Static holder field Static accessor

The three ingredients

  • A private constructor so no one else can call new.
  • A private static field that holds the single instance.
  • A public static method (getInstance()) that returns it.

1 · Basic (lazy) Singleton

Simple and fine for single-threaded use — but not safe if two threads call getInstance() at the same time.

public class BasicSingleton {

    private static BasicSingleton instance;

    private BasicSingleton() { }        // no external instantiation

    public static BasicSingleton getInstance() {
        if (instance == null) {        // two threads can both pass this check!
            instance = new BasicSingleton();
        }
        return instance;
    }
}
Race condition: if two threads hit the null check together, you can end up with two instances. Use one of the thread-safe variants below.

2 · Thread-Safe (synchronized method)

The simplest fix — synchronize the whole method. Correct, but every call pays a locking cost even after the instance exists.

public class ThreadSafeSingleton {

    private static ThreadSafeSingleton instance;

    private ThreadSafeSingleton() { }

    public static synchronized ThreadSafeSingleton getInstance() {
        if (instance == null) {
            instance = new ThreadSafeSingleton();
        }
        return instance;
    }
}

3 · Double-Checked Locking

Locks only on first creation, then runs lock-free. The volatile keyword is essential — it prevents a partially-constructed object from being seen by another thread.

public class DclSingleton {

    private static volatile DclSingleton instance;   // volatile is key

    private DclSingleton() { }

    public static DclSingleton getInstance() {
        if (instance == null) {                         // 1st check (no lock)
            synchronized (DclSingleton.class) {
                if (instance == null) {                 // 2nd check (with lock)
                    instance = new DclSingleton();
                }
            }
        }
        return instance;
    }
}
🧠Check → lock → check again. The second check stops a second thread that was waiting on the lock from creating a duplicate.

4 · Two simpler alternatives

Eager initialization

Create the instance up front. Thread-safe by the JVM's class-loading guarantees — use it when the object is cheap and always needed.

public class EagerSingleton {
    private static final EagerSingleton INSTANCE = new EagerSingleton();
    private EagerSingleton() { }
    public static EagerSingleton getInstance() { return INSTANCE; }
}

Enum Singleton (the "best" way — Effective Java)

Concise, thread-safe, and immune to reflection and serialization attacks for free.

public enum Config {
    INSTANCE;

    public void load() { /* ... */ }
}

// usage
Config.INSTANCE.load();
