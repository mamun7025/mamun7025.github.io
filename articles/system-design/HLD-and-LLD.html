System Design

System Design — HLD vs LLD

Designing a software system means planning it before you build it. HLD describes the big-picture architecture; LLD zooms into each module's internal design. Together they take you from a client requirement all the way to code.

HLD — the blueprint LLD — the wiring diagram

What is system design?

The process of designing any software application before/while building it. Before writing code, you weigh a few things up front:

  • What features will the application have?
  • How many users will access it?
  • How many requests arrive at peak, at any one time?
  • How far do we need to scale — and what's the allowed cost?

It helps to think in real-world terms — how do Twitter, Instagram, WhatsApp or Facebook handle these problems? Borrowing those proven ideas leads to a better design.

High-Level Design (HLD)

The overall architecture — the 30,000-foot view of the system, usually produced by solution architects.

What HLD covers

  • Functional requirements — what the system must do.
  • Non-functional requirements — consistency, availability, performance, scalability.
  • Costing limitations — the budget that shapes the trade-offs.
  • Limitations of the system — known constraints and boundaries.

Low-Level Design (LLD)

The component-level design — how each module is actually built, produced by designers and developers.

What LLD covers

  • UML diagrams — class diagrams, data model / ER diagrams, sequence diagrams.
  • Interfaces — the contracts each module exposes.
  • Coding — the concrete implementation, e.g. fetch all posts, create a new post, reply to a post.

HLD vs LLD at a glance

AspectHLDLLD
ScopeOverall design of the systemComponent / module-level design
Description levelOverall architectureEach and every module in detail
Owned bySolution architectsDesigners & developers
PurposeTurns client requirements into a high-level solutionTurns the high-level solution into a detailed implementation
🧠HLD = what & where (the blueprint).   LLD = how (the wiring diagram that developers build from).
