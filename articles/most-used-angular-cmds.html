Most Used Angular CLI Commands

Angular CLI commands I use while building enterprise apps such as HRMS and payroll modules: serving, scaffolding code, adding libraries and building for production.

Run & serve Generate code Build & deploy

Quick reference — ng generate shortcuts

Short formLong formCreates
ng g cng generate componentComponent (ts, html, css, spec)
ng g sng generate serviceInjectable service
ng g clng generate classPlain TypeScript class / model
ng g mng generate moduleNgModule (optionally with routing)
ng g ing generate interfaceTypeScript interface

1 · Create & run a project

ng new my-crud-app --routing          # new project with a routing module
npm install                           # install dependencies (after cloning)

ng serve                              # dev server on http://localhost:4200
ng serve --open                       # ...and open the browser
ng serve --port 9000                  # use a different port

2 · Generate components, services & classes

Paths are relative to src/app. The CLI creates any missing folders.

Components

ng g c employee-create                           # src/app/employee-create/*
ng g c employee/employee-list                    # src/app/employee/employee-list/*
ng g c emp-profile/components/employee-create    # deeper feature structure

ng g c plainsight/some-name --flat               # src/app/plainsight/some-name.component.ts
                                                 # --flat = no extra folder for the component

Services

ng generate service data                         # src/app/data.service.ts
ng g s emp-profile/services/employee             # emp-profile/services/employee.service.ts

Classes & models

ng g cl emp-profile/models/employee              # employee.ts
ng g class models/tutorial --type=model          # tutorial.model.ts

3 · Feature modules with routing

Group a feature (e.g. Post, Payroll) into its own module with its own routes, then add CRUD pages inside it.

App routing module

ng generate module app-routing --flat --module=app
  # --flat          put the file in src/app instead of its own folder
  # --module=app    register it in the imports array of AppModule

A CRUD feature module

ng generate module post --routing
ng generate component post/index
ng generate component post/view
ng generate component post/create
ng generate component post/edit
Result
src/app/post/
├── post.module.ts
├── post-routing.module.ts
├── index/     (list page)
├── view/      (details page)
├── create/    (create form)
└── edit/      (edit form)

Real-world example — a payroll batch job

ng generate module all-modules/payroll --routing

ng g c all-modules/payroll/salary-process/batch-job/list/salary-process-job-list     --flat
ng g c all-modules/payroll/salary-process/batch-job/show/salary-process-job-show     --flat
ng g c all-modules/payroll/salary-process/batch-job/create/salary-process-job-create --flat
ng g c all-modules/payroll/salary-process/batch-job/edit/salary-process-job-edit     --flat
🧠Use the same list / show / create / edit folder names in every feature module. Every screen then lives in a predictable place, which makes large apps easier to navigate.
Angular 17+: new projects use standalone components by default, so NgModules are optional. The module commands above are still the standard for existing module-based apps.

4 · Add third-party libraries

npm install bootstrap
npm install font-awesome

# jQuery DataTables with Angular wrapper + type definitions
npm install jquery datatables.net datatables.net-dt angular-datatables
npm install --save-dev @types/jquery @types/datatables.net

npm uninstall ngx-spinner              # remove a package
Note: since npm 5, npm install saves to package.json by default, so --save is no longer needed. Use --save-dev for build-time-only packages such as type definitions.

5 · Build for production

Output goes to dist/. Set --base-href when the app is served from a sub-path instead of the domain root.

ng build                                          # production build (default in Angular 12+)
ng build --base-href .                            # relative paths — open from any folder
ng build --base-href /hrms/                       # app served at https://example.com/hrms/
ng build --base-href https://www.example.com/     # absolute base URL
Older Angular (≤ 11): use ng build --prod --base-href=/hrms/ --deploy-url=/hrms/. --prod was removed in newer versions, use --configuration production instead. --deploy-url is deprecated.
